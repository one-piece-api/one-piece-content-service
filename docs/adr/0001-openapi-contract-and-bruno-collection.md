# ADR-0001: OpenAPI contract, Swagger UI and Bruno collection

## Context

Same need as `one-piece-user-service`: a machine-readable contract, Swagger UI, and a
Bruno collection that stays in sync on its own, for the local and remote environments.
The full rationale and the alternatives are in that repo's ADR-0014. This record covers
the adoption here and the one point where this service differs.

## Decision

Same setup as `one-piece-user-service` ADR-0014:

- A code-first spec with springdoc, served with Swagger UI behind login at
  `/api/content/swagger-ui.html`.
- Committed as `openapi/openapi.yaml` and kept in sync by `OpenApiSpecTest` and
  `./gradlew updateOpenApiSpec`.
- `x-required-permission` read from `SecuredEndpoint`, and error responses from
  `one-piece-exception` 0.2.0.
- A Bruno collection in `bruno/`, regenerated by `scripts/generate-bruno-collection.sh`,
  using the `bruno` Keycloak client and the `dev` (IntelliJ, `localhost:8082`)/`local`/`remote`
  environments.
- A CI `api-contract` job.

**Difference: operationIds scoped by controller.** Here the handler methods are short verbs
meant to be read within their controller (`list`, `get`, `create`, ...). They collide in the
spec's flat operationId namespace, and springdoc would add unstable `_1`/`_2` suffixes.
An `OperationCustomizer` in `OpenApiConfig` prefixes each one with its controller
(`languageList`, `reviewQueueGet`, `devilFruitTypeCreate`).

## Alternatives considered

- **Renaming every handler method**: 25 renames only to satisfy a naming concern of the
  spec, and nothing would stop the next short verb from colliding again.
- **`@Operation(operationId = ...)` on every method**: explicit, but it's per-method
  boilerplate that a new endpoint can forget.

## Consequences

- OperationIds (and therefore Bruno request names) follow the controller they belong to.
  Moving a handler to another controller renames its operation, and CI's oasdiff report
  shows that.
- The workflow after an API change is the same as in user-service: `./gradlew
  updateOpenApiSpec`, then `scripts/generate-bruno-collection.sh`, then commit both.
